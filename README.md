#  2º Cérebro para Transformar Dados em Soluções

Este repositório documenta meu projeto desenvolvido durante o Bootcamp DIO + Bradesco, utilizando o NotebookLM como ferramenta de organização e inteligência aplicada. O objetivo é reunir, conectar e aplicar conhecimentos em **programação, análise de dados e IA** para resolver problemas reais.

##  Objetivo
Criar um "segundo cérebro" digital que transforma aprendizado em soluções práticas, com foco em:
- Programação (HTML, CSS, JS, Python)
- Análise de dados (SQL, Power BI, Pandas)
- Inteligência Artificial aplicada (NotebookLM, automações, insights)

##  Estrutura do NotebookLM
- 61 fontes organizadas (artigos, vídeos, guias)
- Resumos sobre IA, estatística, análise de dados e ferramentas
- Conexões entre conceitos técnicos e aplicações empresariais
